# Analisis Data Penjualan dari Deskriptif sampai Prediktif

## Studi kasus
Studi kasus: membersihkan data transaksi sederhana, merangkum penjualan, melihat produk terlaris, memprediksi penjualan secara demonstratif, lalu memberi rekomendasi stok. Prediksi hanya contoh pembelajaran.

## Implementasi
Kode pada proyek ini menunjukkan penerapan konsep materi dalam skala mini. Data contoh disediakan di folder `data/`.

## Cara menjalankan
```bash
pip install -r requirements.txt
python main.py
```

## Interpretasi dan batasan
Gunakan hasil sebagai demonstrasi alur kerja. Untuk penerapan nyata, gunakan data yang dapat dipertanggungjawabkan, lakukan validasi, dan dokumentasikan asumsi serta keterbatasan.
